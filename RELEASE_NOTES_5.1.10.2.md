# Aethernfall 5.1.10.2

UI readability hotfix based on 5.1.10.1.

- Removed the bulky dark background blocks behind transient text overlays.
- Loot ticker and centered toast now render as floating text without large opaque plates.
- Quest tracker, zone badge and zone objective overlays no longer use dark text plates.
- NPC labels and discovery labels are now drawn as outlined text instead of dark rectangles.
- Preserved text readability with shadow/outline styling.
- Bumped the version to 5.1.10.2 so the updated PWA assets invalidate stale caches.

After deployment, fully close the old PWA/Safari tab and open the game online once to ensure the service worker updates.
