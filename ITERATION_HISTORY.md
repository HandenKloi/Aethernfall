# Aethernfall — v1.0 → v2.0 iterative development history

1.2 Stability — dodge movement, entity cleanup.
1.3 Combat — combos, crits, combat feedback, stamina.
1.4 NPC/Quest — dialogue handoff and progression.
1.5 Loot/Equipment — persistent loot and stat effects.
1.6 Navigation — landmarks and minimap improvements.
1.7 Crafting — additional recipe and rewards.
1.8 Performance — viewport culling and cheaper effects.
1.9 Reliability — autosave and orientation/visibility recovery.
2.0 Integration — real rendered-frame monitor/limiter, expanded visuals, integrated systems, mobile-only input.

Each milestone was followed by Node.js syntax checks and structural tests. Final RC 2.0 was additionally exercised with a mocked mobile runtime; the FPS limiter produced ~30 rendered FPS when set to 30.
