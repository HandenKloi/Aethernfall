# Aethernfall 3.2.0

Мобильная 2.5D action RPG на vanilla JavaScript и Canvas. Статический проект: backend, npm, сборка и Node.js для игры не нужны. Основная целевая конфигурация — iPhone 14 Pro Max / Safari; управление через touchscreen.

Исходная точка — предоставленный `Aethernfall_v3_1_1_STABLE.zip`. Три зоны, NPC, цепочки заданий, атаки/комбо, три навыка, блок, уклонение, лут, экипировка, обе рецептуры и прогрессия сохранены.

## Публикация

1. Распакуйте архив. Поместите **его содержимое** в публикуемую папку GitHub-репозитория: `index.html` должен находиться непосредственно в ней.
2. В Settings → Pages выберите публикацию из нужной ветки и папки. Дополнительная сборка не требуется; `.nojekyll` включён.
3. Откройте выданный GitHub Pages HTTPS-адрес. Все игровые пути относительные: поддерживаются корень домена и `/repository/`.
4. В Safari добавьте сайт на экран «Домой»; если доступен переключатель открытия как веб-приложения, включите его.
5. Дайте первоначальной загрузке завершиться при наличии сети. Затем проверьте запуск с иконки без сети.

[GitHub: источник публикации Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). [Apple: добавление сайта на экран «Домой»](https://support.apple.com/ru-ru/guide/iphone/iph42ab2f3a7/ios).

## Обновление

Загружайте полный комплект файлов одной версии. Service Worker устанавливает полный комплект ресурсов; прерванная установка не заменяет рабочую версию. Обновление проверяется при запуске, возвращении приложения и восстановлении сети. Кнопка «Обновить игру» сохраняет прогресс, активирует готовую версию и перезагружает игру. Без нажатия текущая сессия продолжает работать; ожидающий worker также может активироваться после закрытия всех его клиентов.

Для следующего релиза изменяйте `BUILD_VERSION` в `game.js`, `VERSION` в `sw.js`, версии ссылок/текст в `index.html`, `manifest.json`, `selftest.html` и документацию. Текущая версия везде — **3.2.0**. Числа в тестовых фикстурах обновления и исторических отчётах не являются версией приложения.

## Сохранения

Ключ `aethernfall_save_v30` намеренно сохранён ради совместимости. JSON теперь содержит `schemaVersion: 1` и версию приложения. Читаются старые ключи v27/v21/v11. Сохраняются координаты, инвентарь, экипировка и квесты; временные cooldown/block/combo сбрасываются при загрузке. Неизвестные поля верхнего уровня и инвентаря сохраняются при записи.

Автосохранение — каждые 15 секунд активной игры, при важных игровых действиях и уходе в фон. Повреждённый JSON предварительно копируется в ключ с суффиксом `_recovery_<timestamp>`; если резервную копию записать невозможно, перезапись запрещается. Не удаляйте данные сайта для обновления версии. Хранилища браузера и установленного приложения могут быть изолированы; автоматический перенос между ними не заявляется.

Мир, противники и ресурсы пересоздаются при загрузке, как в исходной игре; временный лут и частицы не входят в сохранение. Эта версия не добавляет постоянное сохранение всего состояния мира.

## Качество и управление

- Для iOS профиль по умолчанию — Medium, ограничитель — 60 FPS. Доступны 30/40/45/60; симуляция работает с шагом 1/60 независимо от ограничения отрисовки.
- DPR профилей: до 1 / 1.25 / 1.5 / 1.75, дополнительно не более 1.5 млн внутренних пикселей Canvas.
- Джойстик — движение; атака — ближний удар/комбо; уклонение без движения выполняется по направлению взгляда; блок удерживается пальцем.
- Свайп по свободной правой области меняет направление взгляда. Меню и диалоги приостанавливают симуляцию и сбрасывают удерживаемые действия.
- Настройки графики не меняют число врагов: стандартная зона содержит 17 обычных противников; страж добавляется отдельно.

## Проверки

Откройте `selftest.html` по тому же HTTPS-адресу и нажмите «Запустить проверки». Тесты используют изолированное хранилище в памяти и не меняют игровой прогресс.

Для разработки доступны проверки без npm-зависимостей:

```sh
node tests/run.cjs
node tests/sw.test.cjs
python3 tests/check.py
```

Node/Python нужны только для этих команд. Для локальной игры можно использовать любой статический HTTP-сервер. `file://` не подходит для проверки PWA.

Подробности: [CHANGELOG.md](CHANGELOG.md), [отчёт](docs/TEST_REPORT.md), [архитектура и производительность](docs/AUDIT.md), [проверка на iPhone](docs/IPHONE_CHECKLIST.md).

**Граница проверки:** автоматические тесты выполнены в Node с моделями DOM/Canvas/Cache API. В среде не удалось открыть проект в реальном браузере. Физический iPhone, Safari/WebKit, фактическая установка PWA, визуальная раскладка и нагрев требуют проверки по приложенному чек-листу; аппаратно подтверждённый статус stable не заявляется.
