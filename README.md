# Aethernfall — Release Candidate

Оригинальная 2D Action RPG для iPhone, выполненная как самостоятельный проект с механиками action-MMORPG: ручной бой, блок, уклонение, активные навыки, сбор ресурсов, квест, лут/награды, крафт, уровни, две загружаемые зоны и автосохранение.

## Что внутри
- Canvas 2D без внешних игровых библиотек;
- работает в Safari и в режиме PWA на iPhone;
- сенсорный джойстик + action-кнопки;
- ПК-управление для тестирования;
- две отдельные игровые зоны с переходом и загрузкой;
- три типа противников + элитный страж;
- ручная боевая модель;
- три активных навыка;
- stamina, XP, уровни, золото;
- ресурсы и крафт;
- NPC-квест;
- инвентарь;
- мини-карта;
- локальное сохранение;
- offline cache через Service Worker.

## Запуск
Нужен локальный или HTTPS web-сервер (Service Worker в `file://` не работает).

Например:

    python3 -m http.server 8080

Открыть в Safari/Chrome:

    http://localhost:8080

Для iPhone разместить папку на любом HTTPS-хостинге или использовать локальную сеть с web-сервером; затем открыть страницу в Safari и выбрать «На экран Домой».

## Важное ограничение
Это релизный PWA/web prototype, а не подписанный IPA для App Store. Для нативной публикации в App Store нужна Apple-среда сборки и подпись.

## Управление
ПК: WASD, мышь, Shift, Space, Q/E/R, F, C, I.

iPhone: левый джойстик, атака, уклонение, блок и 3 навыка.
