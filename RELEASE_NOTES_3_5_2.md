# Aethernfall 3.5.2

## Added
- Отдельная круглая кнопка «Задания» с двумя скрещёнными мечами.
- Экран текущего задания: зона, название, четыре этапа, текущая цель со
  счётчиками и отметки пройденных этапов. Открытие не продвигает квест.
- Отдельная круглая кнопка магазина с изображением торговой лавки.

## Improved / Mobile / Visual
- Кнопка «Меню» стала круглой с тремя горизонтальными линиями, размер 44×44 CSS px.
- Новые круглые кнопки имеют тот же размер, промежутки 6 px, доступные названия
  и SVG-иконки без внешних ресурсов. Кнопка «Сумка» сохраняет текст.
- Панель героя подстраивается под доступную ширину рядом с четырьмя кнопками.
  Сохранены safe area и существующие правила для узкого/горизонтального экрана.
- Магазин убран из сумки и открывается непосредственно из верхней панели.

## Fixed
- Кнопка возврата из магазина теперь закрывает его и возвращает в игру,
  а не открывает сумку. Закрытый магазин не принимает покупку.
- Журнал заданий сбрасывает активное движение через общий механизм модальных
  окон; просмотр этапов не изменяет сохранения и прогресс.
- Исправление наклеенной брони из 3.5.1 сохранено.

## Performance / Internal
- Отрисовка частей персонажа использует общую функцию вместо создания нового
  замыкания для каждого персонажа на каждом кадре. Геометрия анимации сохранена.
- Текст текущей цели вычисляется один раз за обновление HUD вместо двух.
- Состояние disabled кнопки расходника записывается в DOM только при изменении.
- Сохранены игровые механики, снаряжение, расходники и схема сохранений 2.

## PWA
- Версии UI, кода, manifest, URL ресурсов и Service Worker: 3.5.2.
- Относительные пути и атомарный офлайн-кэш сохранены. Новых зависимостей нет.
- Для публикации замените содержимое папки GitHub Pages файлами архива,
  включая art.js и assets. Не очищайте данные сайта: там находятся сохранения.
- tests/, docs/ и selftest.html в production-архив не включены.

## Проверки
- 73 проверки логики/управления/сохранений и новых экранов в Node VM.
- Включены проверки прямого открытия магазина, отсутствия его кнопки в сумке,
  возврата в игру, паузы при открытии заданий, всех четырёх этапов трёх зон.
- 12 проверок модели Service Worker в корне сайта и /repository/.
- 27 статических проверок: синтаксис, ресурсы, HTML ID, manifest, версии и CSS.
- Программная отрисовка Canvas: 12 сочетаний зон/качества, 240 поз персонажей.
- Проверки не заменяют физический Safari: компоновка браузера, сенсорное
  управление и фактический FPS на iPhone здесь не измерялись.

## На iPhone 14 Pro Max
1. После обновления проверить версию 3.5.2 и четыре кнопки верхней панели.
2. Проверить круглый вид меню/заданий/магазина и удобство касаний, затем повернуть экран.
3. Открыть задания при движении: герой должен остановиться, этап совпасть с HUD.
4. Открыть магазин напрямую, купить предмет, вернуться в игру; проверить сумку.
5. Проверить старое сохранение, возврат из background и офлайн-запуск PWA.
