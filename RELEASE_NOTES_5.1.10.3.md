# Aethernfall 5.1.10.3

Gameplay/UI hotfix on top of 5.1.10.2.

- Fixed dropped loot rendering so resource drops no longer appear as generic geometric figures.
- Kept painterly resource visuals for herb / wood / ore loot and improved fallback drawings for coin / token / shard drops.
- Removed 40 FPS and 45 FPS options from graphics settings.
- Removed the "EN" unit from action button cost labels; only numeric cost remains.
- Improved menu and gameplay text fitting inside buttons and segmented controls.
- Added compact current/maximum numeric values to the three top HUD bars.
- Added a subtle adaptive pill background for current quest progress lines with counters such as 0/2.
- Shortened contextual action labels for better fit on mobile controls.
- Bumped version to 5.1.10.3 for cache invalidation.

After deployment, fully close the old PWA / Safari tab once and reopen the game online so the service worker refreshes.
