# Aethernfall 5.1.10.4

Action-button UI cleanup on top of 5.1.10.3.

- Removed stamina/energy cost numbers from gameplay action buttons completely.

- Cooldown time remains visible in seconds only while a cooldown is active.
- Gameplay stamina costs themselves are unchanged; this is an interface-only change.
- Bumped version to 5.1.10.4 for PWA cache invalidation.
