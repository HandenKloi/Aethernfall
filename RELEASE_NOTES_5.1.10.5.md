# Aethernfall 5.1.10.5

Visual/UI hotfix on top of 5.1.10.4.

- Fixed the camp side-quest board highlight marker so the interaction circle now sits under the board instead of off to the side.
- Reworked the camp board from a plain geometric placeholder into a more painterly wooden sign that better matches the environment.
- Polished text alignment in settings tabs, graphics buttons and gameplay control buttons.
- Removed the enemy shot direction guide line for marksman mobs.
- Removed the circular recovery / delay indicator for regular mobs while keeping boss combat telegraphs intact.
- Bumped version to 5.1.10.5 for cache invalidation.

After deployment, fully close the old Safari / PWA tab once and reopen the game online so the refreshed service worker activates.
